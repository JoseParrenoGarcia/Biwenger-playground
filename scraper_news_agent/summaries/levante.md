# Levante UD

## Injuries
- **Alfonso Pastor**: Underwent successful surgery for a finger fracture; expected to be out for four weeks.
- **Carlos Álvarez**: Suffering from pubalgia, training individually and will miss the start of the season.
- **Matías Moreno**: Injured in the rectus femoris; unlikely to be available for the first match.
- **Kervin Arriaga**: Also dealing with a rectus femoris injury; expected to miss the start of the season.
- **Alan Matturro**: Injured since July 18; not expected to return for the opening match.
- **Jon Ander Olasagasti**: Suffered a similar injury to Arriaga and Moreno; doubtful for the first match.

## Transfers
- **Óscar Clemente**: Contract rescinded; played 33 matches for Levante, scoring one goal.
- **Goduine Koyalipou**: Signed on loan from RC Lens with an option to buy.
- **Manu Sánchez**: Joined on loan from Celta de Vigo.
- **Unai Elgezabal** and **Roger Brugué**: Newly appointed captains for the season.
- **Etta Eyong**: In negotiations for a potential loan from Villarreal.
- **Iker Losada**: Negotiations ongoing for a loan from Real Betis with an option to buy.
